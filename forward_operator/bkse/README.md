# BKSE nonlinear blur model

This directory contains the pretrained KernelWizard network components used
by SGPS's nonlinear blur operator. Training scripts and unrelated solvers are
not included.

- Original project: [BKSE](https://github.com/VinAIResearch/blur-kernel-space-exploring)
- Paper: *Explore Image Deblurring via Encoded Blur Kernel Space*, Phong Tran,
  Anh Tran, Quynh Phung and Minh Hoai, CVPR 2021.
- Network options: [default.yml](options/generate_blur/default.yml)
- Original license: [LICENSE](LICENSE)

The backbone code is based on [DeblurGAN](https://github.com/KupynOrest/DeblurGAN).
Please cite the BKSE paper when using this component in published work.
